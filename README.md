# ScreenTap

روشن/خاموش کردن صفحه با دو ضربه روی بدنه گوشی (اندروید ۶+).

## ساخت APK بدون کامپیوتر
1. یک ریپازیتوری جدید در GitHub بسازید و محتوای این پوشه را آپلود کنید.
2. به تب Actions بروید ← Build APK ← پس از پایان، فایل ScreenTap-APK را دانلود کنید.
3. APK را روی گوشی نصب کنید (نصب از منابع ناشناس را فعال کنید).

## ساخت با Android Studio
پوشه را باز کنید ← Build ← Build APK(s).
